# [Dark Mode](https://www.mousehuntgame.com/preferences.php?tab=mousehunt-improved-settings#mousehunt-improved-settings-native-dark-mode)

Adds a dark mode to MouseHunt. Please disable the MHCT dark mode option or the MouseHunt Dark Mode extension when using this feature.

## Options

- **Mice Page Image enhancements**: Modifies the image display on the mice page. (Enabled by default)
- **Tint journal entries** (Beta): Use darker shades of the game's event and location colors.

## Color schemes

**Dark Mode Color Schemes** (Experimental, under Personalization) offers a **Color scheme** picker for dark or light interface colors and a **Theme preset** picker that also applies matching page and camp backgrounds, shield, horn, and HUD. Selecting a color scheme turns on Dark Mode.
