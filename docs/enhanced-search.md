# [Enhanced Search](https://www.mousehuntgame.com/preferences.php?tab=mousehunt-improved-settings#mousehunt-improved-settings-feature-enhanced-search)

Find items by their abbreviations, so searching "ESB" turns up Empowered SUPER|brie+.

## Options

Choose where abbreviation search works. All are enabled by default.

- **Inventory**
- **Trap Selector**
- **Marketplace**
- **Send Supplies**
