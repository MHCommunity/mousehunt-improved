# [Hide page elements](https://www.mousehuntgame.com/preferences.php?tab=mousehunt-improved-settings#mousehunt-improved-settings-hide-page-elements)

Hide parts of the page you don’t use. Choose which ones to hide:

- **Sidebar**, which moves to a "Sidebar" dropdown in the top menu (hidden by default).
- **Ads** for Feedback Friday, the mobile apps, and more.
- **Share buttons** (hidden by default).
- **News ticker** in the header (hidden by default).
- **Hunters Online and Friends Online bar** above the HUD.
- **Footer**
- **Daily Draw** inbox tab and its notifications.
- **Daily reward popup**, which is closed automatically.
