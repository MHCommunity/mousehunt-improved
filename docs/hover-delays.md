# [Hover Delays](https://www.mousehuntgame.com/preferences.php?tab=mousehunt-improved-settings#mousehunt-improved-settings-hover-delays)

Adds a short delay before menus and tooltips open, so they don’t pop up as you move the mouse past them.

## Options

- **Delay menu dropdowns**
- **Delay tooltips**: Hold Shift to show tooltips right away.
