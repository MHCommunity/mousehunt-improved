# [Max Title](https://www.mousehuntgame.com/preferences.php?tab=mousehunt-improved-settings#mousehunt-improved-settings-fabled-max-title)

Change what the HUD shows in place of the title progress bar once you reach Fabled. Only shown to Fabled hunters.

## Options

- **Show**: Custom text, a random title that changes every hunt, or the completed progress bar.
- **Custom text**: The text to show when Show is set to custom text.
